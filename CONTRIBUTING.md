# Contributing to Awesome Active Inference

Thanks for helping build the best on-ramp to Active Inference and the Free Energy Principle!

## What belongs here

High-quality, durable resources that help someone **learn** or **build** with active inference / the FEP — across both neuroscience/cognitive science and AI/ML. Papers, textbooks, tutorials, courses, videos, software, blogs, and people/organizations are all in scope.

## Entry guidelines

1. **Place it in the right section.** If unsure between two sections, pick the one matching the resource's primary contribution.
2. **Keep sections chronological.** Within a section, order entries by publication or release year (oldest first) so readers can follow the development of ideas.
3. **Note books as books.** Mark a book with "(book)" after the title. Everything else is assumed to be a paper unless noted (for example, "(blog)" or "(course)").
4. **Add a one-line note** explaining why the resource matters, not just what it is.
5. **Prefer stable, open links.** Order of preference: open-access publisher page, then arXiv or PMC, then an institutional PDF. Avoid paywalled-only links when an open version exists. Use a short, readable label for the link (for example, `[arXiv]`, `[PMC]`, `[MIT Press]`).
6. **No duplicates.** Check whether the resource is already listed, possibly under another section.
7. **Keep the style plain.** Avoid emoji and decorative formatting; the list should read cleanly for humans.

## Format

```markdown
- [ ] Author (Year). *Title*. One-line reason it matters. [arXiv](URL)
```

Entries in the reading sections begin with a task-list checkbox (`- [ ]`) that serves as a "Read?" column. New entries should be added unread (`- [ ]`).

## How to submit

1. Fork the repo and create a branch (`feature/add-<short-name>`).
2. Edit `README.md`.
3. Open a pull request describing the addition and why it belongs.

## Removing entries

If a link is dead with no archive, or a resource has been superseded and adds no historical value, open a PR removing it with a brief rationale.
